NetWatch privacy policy

Effective from 17 October 2026 · developer: L1TTLEHE11

In short

NetWatch does not collect, sell or share your data. The app has no ads, no analytics, no accounts and no developer servers. This website has no analytics, no cookies and loads nothing from third-party servers.

Data processed on the phone

  • Network parameters: Wi-Fi name and signal, IP addresses, gateway, DNS — for display and diagnostics.
  • Measurement results: pings, speed, devices found on the local network, survey points, monitor sessions.
  • Addresses and settings you enter, including the MikroTik address, login and (if you choose “remember”) password.

All of this is stored only in the app’s private folder on your device and is deleted together with the app or with the “Clear” button in “History”.

Location

Location permission is requested only because Android does not give apps the Wi-Fi network name (SSID) and scan results without it. Coordinates are never requested, used or stored.

Network requests

To work, the app connects to:

  • devices on your local network and hosts you choose — ping, scanning, traceroute, ports, MikroTik;
  • public servers for the speed test (mirror.yandex.ru, mirror.selectel.ru, speed.cloudflare.com, speed.hetzner.de) and DNS servers for the DNS test;
  • GitHub and jsDelivr — to check for and download updates (automatic checks can be turned off in settings). The F-Droid version has no built-in updater and never contacts them.

These servers see your IP address, as with any website. The app sends them no device or user identifiers.

Sharing

Data leaves the phone only when you act — when you share a PDF, TXT or CSV report yourself via the “Share” menu.

Website

The site is hosted on GitHub Pages, which may keep technical server logs (such as IP addresses) under the GitHub privacy statement. The site itself only remembers your language choice in your browser’s local storage.

Children

The app is not intended for children and collects no data about them.

Changes and contact

Changes to this policy are published on this page. Questions: GitHub issues. The source code is open: github.com/L1TTLEHE11/NetWatch.
