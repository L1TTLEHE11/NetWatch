Monitor a MikroTik router from your phone

Winbox is great at a desk. Walking around a building, you want the same answers in your pocket: is the router overloaded, which port is busy, which access point a client is on and how strong its signal is.

1. Enable the API on the router

In Winbox or WebFig open IP → Services and enable api (port 8728) or api-ssl (port 8729). In the terminal:

/ip service enable api
/ip service set api address=192.168.88.0/24

The second line allows API access only from your local network — don’t expose the API to the internet.

2. Create a read-only user

NetWatch only reads data, so a user from the read group is enough:

/user add name=netwatch group=read password=YOUR-PASSWORD

3. Connect from NetWatch

Open More → MikroTik in NetWatch, enter the router address (usually the gateway shown on the home screen), the user and the password. Tick “remember password” if you want — the password is stored only on your phone. Works with RouterOS v6 and v7.

4. What you see

  • System: identity, model, RouterOS version, uptime, temperature, CPU and memory load.
  • Interfaces: live download and upload on every port and bridge.
  • CAPsMAN: managed access points and their state.
  • Wi-Fi clients: which access point and band each client uses, its signal and connection time.
  • DHCP leases: IP, MAC and host name of every device.

5. Use it with the other tools

Once a MikroTik is connected, the network scanner shows MAC addresses and names from the router. Combine it with Wi-Fi → Site survey to walk a building and map the signal of every access point, and with Monitoring to catch uplink outages.
