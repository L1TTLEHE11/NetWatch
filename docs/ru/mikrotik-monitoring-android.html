Мониторинг MikroTik с телефона

За столом есть Winbox. А когда ходишь по зданию, те же ответы нужны в кармане: не перегружен ли роутер, какой порт занят, к какой точке подключён клиент и какой у него сигнал.

1. Включите API на роутере

В Winbox или WebFig откройте IP → Services и включите api (порт 8728) или api-ssl (порт 8729). В терминале:

/ip service enable api
/ip service set api address=192.168.88.0/24

Вторая строка разрешает доступ к API только из локальной сети — не открывайте API в интернет.

2. Создайте пользователя только для чтения

NetWatch только читает данные, поэтому хватит пользователя из группы read:

/user add name=netwatch group=read password=ВАШ-ПАРОЛЬ

3. Подключитесь из NetWatch

Откройте Ещё → MikroTik в NetWatch, введите адрес роутера (обычно это шлюз с главной экрана), пользователя и пароль. Можно отметить «запомнить пароль» — пароль хранится только на телефоне. Работает с RouterOS v6 и v7.

4. Что вы увидите

  • Система: имя, модель, версия RouterOS, аптайм, температура, загрузка CPU и памяти.
  • Интерфейсы: скачивание и отдача на каждом порту и бридже в реальном времени.
  • CAPsMAN: управляемые точки доступа и их состояние.
  • Wi-Fi клиенты: к какой точке и диапазону подключён каждый клиент, его сигнал и время подключения.
  • DHCP-аренды: IP, MAC и имя каждого устройства.

5. Используйте вместе с другими инструментами

Когда MikroTik подключён, сканер сети показывает MAC-адреса и имена из роутера. Вместе с Wi-Fi → Обход объекта можно пройти здание и составить карту сигнала каждой точки, а Мониторинг поймает обрывы канала до провайдера.
