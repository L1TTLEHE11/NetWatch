# NetWatch: Network Scanner

`NETWATCH // TOOL` для Android.

Сетевой диагностический инструмент в стиле Cyberpunk 2077: сканер локальной сети, анализатор Wi-Fi эфира, обход объекта с замерами, фоновый мониторинг обрывов, traceroute, DNS-тест, сканер портов, Wake-on-LAN, подключение к MikroTik, PDF-отчёты и виджет. Изначально — Android-порт десктопной версии NetWatch (Python / Tkinter).

## Возможности

### [01] Живой дашборд
- **Радиосканер.** Сила сигнала Wi-Fi в dBm с live-графиком, качество в %, SSID, BSSID, диапазон (2.4 / 5 / 6 ГГц), канал и скорость линка. На мобильной сети показывает уровень сотового сигнала и оператора.
- **Пинг до роутера / шлюза.** Шлюз определяется автоматически, задержка рисуется на графике в реальном времени.
- **Пинг до внешнего узла.** Любой IP или хост, по умолчанию `8.8.8.8`.
- **Сетевые интерфейсы и маршруты.** Аналог `ipconfig /all`: адреса, шлюз, DNS, MTU, тарификация, стандарт Wi-Fi и все поднятые интерфейсы.

### [02] Интернетометр
- Замер запускается кнопкой и идёт по этапам: **пинг и джиттер → скачивание → отдача**.
- Скачивание идёт в 8 потоков, отдача в 6. Скорость пересчитывается 10 раз в секунду, цифры и шкалы «бегут» во время замера.
- Итоговая скорость считается без разгона TCP (первые 25% времени не учитываются).
- Серверы: mirror.yandex.ru, mirror.selectel.ru, speed.cloudflare.com, speed.hetzner.de. Выбирается первый доступный.
- Есть график скорости по ходу замера и история последних 10 замеров.

### [03] Сканер сети
- Находит все устройства в подсети за 10–30 секунд: ICMP + TCP-пробы (видит и iPhone, и компьютеры с закрытым ping).
- Для каждого устройства: IP, отклик, открытые порты, имя (NetBIOS / DNS), заголовок веб-интерфейса и **тип устройства** — роутер, MikroTik, IP-камера, принтер, Smart TV, iPhone, компьютер Windows, NAS.
- С подключённым MikroTik добавляет MAC-адреса и имена из DHCP/ARP роутера.
- Из карточки устройства — сразу в пинг, сканер портов или MikroTik.

### [04] Wi-Fi эфир
- Все сети вокруг: SSID, BSSID, сигнал, канал, ширина канала (20–320 МГц), шифрование.
- График загрузки каналов 2.4 / 5 / 6 ГГц, как в Wi-Fi Analyzer.
- **Рекомендация лучшего канала** по реальной загруженности эфира (для 5 ГГц — среди каналов без DFS).

### [05] Обход объекта
- Встаёте в точку, вводите название («номер 204», «ресепшн») — записываются сигнал, точка доступа, пинг и потери до роутера и интернета, по желанию скорость.
- Проблемные точки подсвечиваются автоматически; результаты сохраняются между запусками.
- Выгрузка в **CSV (открывается в Excel)** и **PDF**.

### [06] Диагностика
- **Traceroute** — каждый узел по пути в интернет с задержкой.
- **Тест DNS** — сравнение DNS провайдера с Google, Cloudflare, Яндекс, Quad9, AdGuard.
- **Сканер портов** — популярные, 1–1024 или все 65535, с расшифровкой служб.

### [07] Локальная сеть
- **Live-пинг любого узла** со статистикой мин / сред / макс и потерь.
- **Многопоточный TCP-тест пропускной способности** до устройства в сети.
- **Wake-on-LAN** — включение компьютера по сети, список сохранённых устройств.

### [08] Мониторинг
- Фоновая проверка роутера и интернета каждые 2 секунды, даже когда приложение свёрнуто.
- **Уведомления об обрывах и восстановлении связи**, статистика потерь, число обрывов и общее время без связи, журнал событий.

### [09] MikroTik
- Подключение по RouterOS API (8728 / 8729 SSL), RouterOS 6 и 7.
- Модель, версия, аптайм, CPU, память, температура; трафик по интерфейсам в реальном времени.
- Точки доступа CAPsMAN, клиенты Wi-Fi с уровнем сигнала, DHCP-аренды.

### [10] История
- Всё сохраняется автоматически: замеры скорости, сканы сети, сессии мониторинга (с записью раз в минуту — не теряются, даже если систему убьёт приложение), traceroute, тесты DNS и портов, архив обходов.
- Записи сгруппированы по дням, фильтры по типу, сети (Wi-Fi объекта) и периоду.
- **Сводка скорости за период**: средняя, минимальная, график во времени, худшее время суток — и выгрузка в Excel.
- Любую запись можно открыть, отправить в PDF/CSV или удалить. Срок хранения — 7 / 30 / 90 дней или всегда.
- Сканер **запоминает устройства** каждой сети: новые помечаются «НОВОЕ», пропавшие показываются отдельно; последний скан виден сразу после запуска.
- Приложение помнит введённые адреса, выбранные настройки и последнюю вкладку.

### Отчёты и виджет
- Кнопка **«📤 ОТЧЁТ»** собирает всё замеренное в один **PDF** или **TXT** и отправляет в любой мессенджер или почту.
- **Виджет** рабочего стола: пинг до роутера и интернета, сигнал Wi-Fi.

## Установка

1. Скачайте [`NetWatch-2.1.1-universal.apk`](https://github.com/L1TTLEHE11/NetWatch/raw/main/apk/NetWatch-2.1.1-universal.apk) (все версии лежат в папке [`apk/`](apk/)).
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. При первом запуске нажмите **«🔓 РАЗБЛОКИРОВАТЬ»** в карточке Wi-Fi. Android показывает имя сети (SSID) только приложениям с доступом к геолокации. Сами координаты приложение не получает и никуда не отправляет.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET` | пинги и замеры скорости |
| `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` | тип сети, шлюз, DNS, параметры Wi-Fi |
| `ACCESS_FINE/COARSE_LOCATION` | без него Android скрывает SSID, BSSID и результаты сканирования эфира |
| `CHANGE_WIFI_STATE` | запуск сканирования Wi-Fi эфира |
| `FOREGROUND_SERVICE`, `WAKE_LOCK` | фоновый мониторинг связи |
| `POST_NOTIFICATIONS` | уведомления об обрывах |

Приложение не собирает и не передаёт никаких данных. Аналитики и рекламы в нём нет.

## Технические детали

- **Kotlin + Jetpack Compose**, minSdk 26 (Android 8.0), targetSdk 35.
- **Пинг** через системный `/system/bin/ping`. Если прошивка его запрещает, приложение автоматически переходит на замер времени TCP-соединения.
- **Фоновый режим.** Когда приложение свёрнуто, все замеры приостанавливаются; работать в фоне продолжает только мониторинг, если его запустили.
- **MikroTik.** Собственная реализация протокола RouterOS API без сторонних библиотек.
- **Тесты.** `./gradlew testReleaseUnitTest` — проверка протоколов RouterOS API, DNS, NetBIOS, Wake-on-LAN, разбора подсетей, сканера портов и хранилища истории.
- **Полноэкранный режим.** Системные панели вызываются свайпом от края экрана.

## Сборка из исходников

```bash
# нужен JDK 17+ и Android SDK (platform 35, build-tools 35)
echo "sdk.dir=/path/to/Android/Sdk" > local.properties
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Release-сборка сейчас подписывается debug-ключом, чтобы её можно было сразу установить. Для публикации в Google Play нужен собственный ключ подписи.
